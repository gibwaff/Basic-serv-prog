### Реализованные требования:
1. **Страницы сайта (3 страницы)**:
   - `index.php` — Введение в серверную веб-разработку;
   - `php_intro.php` — О языке PHP (назначение, возможности);
   - `architecture.php` — Клиент-серверная архитектура Web.
   Все страницы имеют единый макет, содержат один заголовок `<h1>`, не менее двух заголовков `<h2>` и объем текста > 1 Кб на страницу.
2. **Шапка (`header`)**:
   - Фиксированная высота (60px), закреплена сверху (`position: fixed; top: 0; left: 0;`), не реагирует на скроллинг;
   - Темно-зеленый цвет фона (`#1b4d2e`), белый цвет текста.
3. **Подвал (`footer`)**:
   - Фиксированная высота (50px), закреплен внизу (`position: fixed; bottom: 0; left: 0;`), не реагирует на скроллинг;
   - Темно-серый цвет фона (`#2e2e2e`), светло-серый цвет текста (`#d1d5db`);
   - Динамический вывод надписи: `Сформировано DD.MM.YYYY в HH-ii:ss` средствами PHP (`date('d.m.Y в H-i:s')`).
4. **Меню навигации**:
   - Формирование пунктов меню реализовано строго по Листингу А-1.8 (два PHP-включения на каждый пункт);
   - Ссылка на текущую страницу выделена классом `.selected_menu` (шрифт и фон);
   - Ссылки интерактивны и реагируют на наведение курсора мыши (`:hover`).
5. **Заголовок страницы (`<title>`)**:
   - Формируется динамически через переменную `$page_title` средствами PHP (`Беляков Игорь Романович 241-3210. Лабораторная работа № А-1. ...`).
6. **Таблицы**:
   - Каждая страница содержит таблицу из 2 строк и 3 колонок;
   - Первая строка (включая теги `<tr>...</tr>`) полностью генерируется через PHP;
   - Во второй строке теги `<tr>` и `<td>` статичны, а содержимое ячеек формируется динамически через PHP без промежуточных переменных.
7. **Изображения**:
   - Не менее двух фото на каждой странице;
   - Динамическая смена фото (`fotos/foto1.jpg` / `fotos/foto2.jpg`) на одном и том же месте в зависимости от текущей секунды сервера (четная/нечетная) по алгоритму Листинга А-1.1 / А-1.2.
